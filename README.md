# Personal Website

A personal website made with [Hugo](https://gohugo.io) to generate the static website. 

Github hosts it and is available here: https://nicolasguilloux.eu/


## Installation

If you use NixOS, make sure you made `direnv allow` in the directory to automatically install the dependency.

To start the server: `make server`

To build the website: `make build`


## About Claude

You may have notice that Claude is used for this project. I won't deny it, I use it very often for templating or prototyping. 
It is a very handy tool that can get many things done in a blink.

But I want to be clear: I don't use it to write article on by behalf. These articles are written by me only so I can also put my thoughs somewhere. I may use it to write the skeleton of an article, to correct or spot some problematic sentences as well as fix Hugo when I update it and when it breaks everything.

In a nutshell, I use Claude to manage the noise and let me focus on writing articles.
