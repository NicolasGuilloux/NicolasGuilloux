I'm a *senior freelance backend developer* from France, specialised in *PHP / Symfony* since 2019 and freelancing since 2022.
I'm the go-to person for *TDD* and *DDD* in the teams I join, and I always try to push for better code quality, architecture and team practices.

I work from my NixOS / nix-darwin setup, and I love building side projects on my own: homelab, home automation, AI agents...

== 🚀 What I've been up to

* 🏛️ *Now*: Senior Symfony / VueJS developer for a French government digital agency, building apps for the State's interministerial network in a fully offline, locked-down environment. Docker images and GitLab CI/CD optimisation included.
* 🧱 *2026*: Short missions on a *Sylius* multi-channel e-commerce platform for a network of 250 retailers, and on a *.NET / Angular* API in hexagonal architecture.
* 🛒 *2022 → 2026*: Senior Symfony developer on the backend of a major French retailer's drive & delivery website (*millions of orders per year*), microservices on *Azure / Kubernetes*. TDD/DDD referent, hexagonal architecture, Symfony 5 → 7 upgrades, API calls cut by 2 to 3× and hundreds of milliseconds saved per request, and early adopter of AI tooling in the team.
* 🏢 *2022*: Senior Symfony developer for a real estate leader: Ibexa DXP, Elasticsearch, Docker stack cleanup, GitLab CI/CD to Kubernetes.
* 🧪 *2019 → 2021*: Full-stack developer in a Bordeaux startup turned scaleup: TDD/DDD daily, Elm on the front, and several open-source Symfony bundles.
